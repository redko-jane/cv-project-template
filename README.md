\# Сравнение моделей детекции объектов на KITTI



\## Описание

Проект по учебной практике (ознакомительной). Реализован полный цикл разработки ML-решения: 

от постановки задачи до сравнения 5 моделей детекции объектов.



\## Модели

\- YOLO

\- Faster R-CNN

\- SSD

\- EfficientDet

\- DETR



\## Установка

pip install -r requirements.txt
