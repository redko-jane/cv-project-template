\# Сравнение моделей детекции объектов на KITTI



\## Описание

Проект по учебной практике (ознакомительной). Реализован полный цикл разработки ML-решения:

от постановки задачи до сравнения 5 моделей детекции объектов.



\## Модели

\- YOLO

\- Faster R-CNN

\- SSD

\- EfficientDet

\- DETR



\## Установка

pip install -r requirements.txt



\## Веса моделей



Большие файлы весов (`ssd.pth` и `faster\_rcnn.pth`) хранятся в Git LFS. Чтобы скачать их после клонирования репозитория, выполните:



git lfs pull
